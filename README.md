# ПЁЛЬ · IMMERSIVE

Иммерсивный концепт главной страницы ресторана корейской кухни и BBQ
«ПЁЛЬ», Новороссийск. Не лендинг, а сплошной кадр: скролл работает
как камера, каждая сцена перетекает в следующую.

Спокойный editorial-концепт этой же страницы — в репозитории `pelb`.

## Смотреть

Опубликовано через GitHub Pages: настройки репозитория → **Pages** →
Source: `main`, папка `/ (root)`.

Локально:

```bash
python -m http.server 5177
```

Затем открыть <http://localhost:5177>. Локальный сервер обязателен:
страница берёт фотографию в WebGL-текстуру, по протоколу `file://`
браузер запретит это как cross-origin.

## Драматургия

| Сцена | Что происходит |
|---|---|
| 01 | Почти чёрный экран, одна звезда. 별 и ПЁЛЬ приходят с прокруткой. |
| 02 | Звезда растёт в источник света, свет опускается вниз кадра и теплеет. |
| 03 | Дым, и сквозь порог шума **выжигается реальная фотография гриля**. |
| 04 | Закреплённый кадр, пять состояний: выбрать → гриль → жарить → пробовать → повторить. |
| 05 | Горизонтальный поток блюд с разной глубиной. Заголовок стоит позади. |
| 06 | ПЁЛЬ ЦЕХ — смена ритма: светлый разворот, лента производства. |
| 07 | Тишина после движения: зал, медленный параллакс, асимметричная сетка. |
| 08 | Возврат к темноте, звезда, бронирование. |

Переход 02 → 03 сделан в шейдере: порог опускается по прогрессу
скролла, фотография проступает через фрактальный шум, а по границе
идёт раскалённая кромка. Это не кроссфейд — огонь съедает кадр.

## Техника

- **Один WebGL-проход** на сцены 01–03: полноэкранный фрагментный
  шейдер. Three.js не нужен — одна плоскость и один шейдер.
- **Скролл — единственный источник времени.** Все сцены читают одну
  позицию и получают прогресс 0..1, поэтому движение нигде не
  рассинхронизируется. Закрепление — на `position:sticky`.
- **Lenis** подключается с CDN и даёт инерцию. Не загрузился или
  тач-ввод — страница работает на нативном скролле.
- **Фолбэки:** нет WebGL или недоступна текстура — кадр держит
  DOM-фотография. Ловится и потеря контекста.
- **Контраст текста — из композиции, а не из плашек:** источник света
  уходит вниз кадра, фотографии гасятся направленной светотенью прямо
  при сэмплировании текстуры.
- Видео стартуют только в кадре, `preload="none"`, звук выключен и
  включается кнопкой.

## Производительность

DPR ограничен 1.9 на десктопе и 1.4 на мобильном; шейдер считается,
только пока его кадр на экране; на мобильном 3 октавы шума вместо 5.
При `prefers-reduced-motion` время шейдера замирает.

Мобильная версия — не сжатый десктоп: горизонтальные ленты становятся
сетками, рельс сцен убирается, но драматургия сохранена целиком.

## Что стоит сделать перед боевым запуском

- Перегнать PNG в WebP: `bbq.png` 2.6 МБ грузится в текстуру первым.
- Пережать `video/tseh.mp4` — 17 МБ.
- Ссылки «Смотреть меню» ведут на якорь — страницы меню пока нет.
- Добавить `og:`-теги и микроразметку `Restaurant`.
